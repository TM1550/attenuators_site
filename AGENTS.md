# База аттенюаторов

Сначала изучи существующий проект и используй его конфигурацию,
формат записей и механизм проверки дубликатов.

Чтение базы и создание новых локальных JSON разрешены.
JSON для импорта сохраняй в ./imports.
Экспорты базы сохраняй в ./backups.

Сохраняй identity_key существующих записей.
Проверяй дубликаты по identity_key, организму, гену и синонимам.
Используй формат, который принимает существующий импортёр.

Перед записью в базу:
1. Покажи точные добавления, изменения и удаления.
2. Дождись моего явного подтверждения этого пакета.
3. Применяй только подтверждённые изменения.

Не удаляй и не перезаписывай записи без отдельного разрешения.
Не меняй Firebase Rules, права доступа и настройки проекта.
Не публикуй сайт без отдельного разрешения.
Не выводи пароли, токены и сервисные ключи.
